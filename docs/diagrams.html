💡 Suggestions d'évolution prioritaires

Haute priorité

📊 Dashboard KPIs & graphiques

Intégrer Recharts ou Chart.js : effectif par département, taux de présence mensuel, répartition des types de congés, masse salariale.

Haute priorité

📄 Export PDF des bulletins

Backend : générer des PDFs avec iText ou JasperReports. Frontend : bouton "Télécharger" sur PayrollDetail.

Haute priorité

📦 Pagination des API

Remplacer findAll() par findAll(Pageable) côté backend. Ajouter des contrôles page/taille côté frontend.

Haute priorité

🔑 Réinitialisation mot de passe

Configurer JavaMailSender (SMTP). Endpoint /api/auth/forgot-password → lien token par email.

Priorité moyenne

🔔 Notifications temps réel

WebSocket (Spring WebSocket) ou SSE pour alerter les managers d'une nouvelle demande de congé.

Priorité moyenne

🌳 Organigramme interactif

Visualisation de la hiérarchie avec React Flow ou D3.js — départements, chefs, managers, employés.

Priorité moyenne

📝 Journal d'audit

Entité AuditLog avec Hibernate Envers. Tracer : qui a modifié quoi et quand — obligatoire pour la conformité RH.

Priorité basse

⭐ Évaluations de performance

Module dédié : cycles annuels/trimestriels, notation 1–5, objectifs SMART, commentaires manager/employé.
